## Mục tiêu
Thực hành JavaScript cơ bản, DOM, sự kiện và jQuery theo 29 Exercise trong ba tài liệu của học phần.

## Cấu trúc
- `index.html`: thông tin sinh viên, giới thiệu và liên kết.
- `css/style.css`: CSS đơn giản dùng chung.
- `Lab08`: 11 Exercise về ngôn ngữ JavaScript.
- `Lab09`: 8 Exercise về DOM và sự kiện.
- `Lab10`: 10 Exercise về jQuery.
- Mỗi Exercise có một file HTML; JavaScript ngoài nằm trong thư mục `js` của Lab.

## Cách xem
Mở https://thanhdat09cpr.github.io/ecommerce-ui-improvement-moc/JavaScript-Labs/ rồi chọn Lab và Exercise.
Có thể chạy bằng Live Server trong VS Code. Bài GET cần HTTP, không mở bằng file://.

## Ghi chú
Ảnh, cờ và jQuery 3.1.1 lấy từ gói thực hành do giảng viên cung cấp. HTML và phần bài làm được viết đơn giản, không dùng framework giao diện.
Exercise 8.1 dùng trang kiểm tra JavaScript cục bộ thay trang PHP cũ. Exercise 9.5 và 9.6 in kết quả ra trang và Console để dễ kiểm tra thay cho alert liên tục.
Exercise 10.9 và 10.10 giữ lựa chọn gọi dịch vụ gốc. Khi kiểm tra, dịch vụ HTTPS bị lỗi chứng chỉ hết hạn. File cities.json là dữ liệu mẫu tự tạo để thực hành GET, không phải kết quả lấy từ dịch vụ gốc.
AI hỗ trợ viết mã, kiểm thử và soạn báo cáo. Phần giới thiệu và tự đánh giá là bản nháp để sinh viên đọc và sửa theo trải nghiệm thực tế.
