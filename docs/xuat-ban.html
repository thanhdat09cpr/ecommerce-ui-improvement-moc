Chạy trên máy

Giải nén đầy đủ, mở index.html. Không cần cài thư viện. Mở docs/bao-cao.html để đọc khảo sát.

GitHub

Tạo repository Public, tải toàn bộ nội dung thư mục dự án lên gốc repository, gồm index.html, css, images, docs, README.md và AI_USAGE.md. Không tải cả thư mục ngoài thành một thư mục con.

GitHub Pages

  1. Settings → Pages.
  2. Source: Deploy from a branch.
  3. Chọn nhánh main, thư mục / (root), Save.
  4. Chờ triển khai, mở URL được GitHub cung cấp.
  5. Kiểm tra CSS, bìa sách, nút mở chi tiết và đường dẫn báo cáo trên URL thực tế.

Trước khi nộp
